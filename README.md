# EnglishSpeak - Онлайн-школа англійської мови

## 📋 Опис проєкту

**EnglishSpeak** — це сучасний міні-сайт для онлайн-школи англійської мови, що пропонує індивідуальні заняття та навчання в міні-групах для дітей та дорослих.

## 📊 Структура даних

### Основні блоки інформації:

**Програми навчання:**
- Англійська для дітей (6-17 років)
- Англійська для дорослих
- Розмовна англійська (70% speaking)
- Підготовка до НМТ/ДПА
- Граматика з нуля
- Англійська для подорожей
- Підготовка до співбесід

**Формати:**
- Індивідуальні уроки (250-350 грн)
- Міні-групи 3-5 осіб (120-150 грн/особа)
- Пробний урок (безкоштовно)

**Викладачі:**
- Олена (С1) - 5 років досвіду, спеціалізація на дітях
- Максим (В2+) - граматика, дорослі та підлітки

**Переваги:**
- 70% уроку — speaking
- Індивідуальний підхід
- Дружня атмосфера
- Професійні викладачі (B2-C1)
- Гнучкий графік
- Контроль прогресу
- Безкоштовний пробний урок
- 100% онлайн

## 🚀 Розгортання

### Платформа:
- **Cloudflare Pages** (готовий до deployment)

### Статус:
- ✅ **Локальна розробка активна**
- ⏳ **Production deployment** - очікує

### Технологічний стек:
- **Backend**: Hono.js (TypeScript)
- **Frontend**: HTML5, Tailwind CSS
- **Icons**: Font Awesome 6.4.0
- **Fonts**: Google Fonts (Montserrat)
- **Deployment**: Cloudflare Pages/Workers

### Команди для розробки:

```bash
# Локальна розробка
npm run dev

# Збірка проєкту
npm run build

# Запуск в sandbox
pm2 start ecosystem.config.cjs

# Deployment на Cloudflare Pages
npm run deploy:prod
```
